# شركة سينما الأسرة الحديدية • Iron Family Cinema Production
### استمارة التعاون المشترك والإنتاج السينمائي • Joint Cooperation Portal

بوابة إلكترونية رسمية متكاملة وثنائية اللغة (عربي • English) لتقديم طلبات التعاون الفني، الرعاية، والإنتاج السينمائي والإعلاني لشركة **سينما الأسرة الحديدية** (Iron Family Cinema Production).

---

## 🌟 الميزات والمواصفات (Key Features)

- **هوية سينمائية أسطورية (3D Cinema Premiere Night):**
  - أجواء العرض الأول في هوليوود مع ستائر مخملية قرمزية مطرزة وحبال ذهبية ثلاثية الأبعاد.
  - بروجكتور سينمائي عتيق يعلو الصفحة مسقطاً حزم ضوئية حجمية (God Rays) وشعاع إضاءة تفاعلي.
  - بكرات أفلام سينمائية وكلاكيت هوليوود ثلاثي الأبعاد مع تأثيرات البارالاكس التفاعلية (Mouse & Gyroscope 3D Parallax).
  - ممشى السجادة الحمراء وأضواء المسرح المتلألئة.
  - كارت استمارة أبيض نقي فاخر (#FFFFFF) محاط بإطار ذهبي مضيء يدور بسلاسة 60fps.

- **حقول استمارة التعاون المشترك (Joint Cooperation Fields):**
  1. **الموضوع • Subject:** مع شرائح اقتراحات ذكية سريعة (إنتاج إعلان، رعاية، فيلم سينمائي، بودكاست وميديا...).
  2. **تفاصيل التعاون • Cooperation Details:** مع عداد رقمي للأحرف (1500 حرف).
  3. **الاسم بالكامل • Your Name:** مع دعم المؤسسات والأفراد.
  4. **البريد الإلكتروني • Email:** مع فحص وتدقيق فوري لصيغة البريد.
  5. **رابط صفحتكم أو موقعكم • Page / Website Link:** مع أيقونة تفاعلية وتوافق كامل.
  6. **مفتاح الدولة ورقم الواتساب • Country Code & Phone:** مع إزالة الصفر الأول تلقائياً لتوافق الواتساب الدولي (+20 وباقي الدول).
  7. **الدولة • Country:** مزامنة ثنائية ذكية بين مفتاح الاتصال واسم الدولة.

- **التكامل الذكي مع واتساب (WhatsApp Routing):**
  - إرسال الرسالة منسقة تلقائياً إلى الرقم الرسمي للإدارة: `https://wa.me/201125566003`.
  - نافذة تأكيد فاخرة مع عد تنازلي وتوجيه تلقائي.

- **النسخ الاحتياطي وإدارة البيانات (Local Storage & Data Export):**
  - حفظ تلقائي فوري لكافة الطلبات في المتصفح المحلي (`localStorage`).
  - سجل استفسارات تفاعلي يمكن فتحه من الهيدر أو الفوتر.
  - إمكانية تصدير البيانات إلى ملفات **CSV (Excel)** و **JSON**.

- **توافق 100% مع الهواتف الذكية (Mobile-First):**
  - دعم كامل لشاشات iPhone و Android من 360px حتى أجهزة سطح المكتب الكبيرة.
  - الستائر والديكورات مثبتة على الحواف لمنع حجب محتوى الاستمارة على الشاشات الصغيرة.
  - حجم خطوط الإدخال 16px لمنع التكبير التلقائي المزعج على متصفحات Safari وChrome للهواتف.
  - بطاقات مشاركة احترافية (Open Graph) تدعم المعاينة الفاخرة على واتساب وتويتر وفيسبوك.

## 🚀 التقنيات المستخدمة (Tech Stack)

- **HTML5:** بنية دلالية (Semantic HTML5) مع وسوم Open Graph كاملة.
- **CSS3:** رسوميات متقدمة، ألوان ملكية سينمائية، تدرجات conic-gradient، وتجاوب كامل (Flexbox & CSS Grid).
- **JavaScript (Vanilla ES6+):** محرك جسيمات Canvas تفاعلي، محرك البارالاكس، التحقق الفوري، وإدارة التخزين المحلي.
- **SVG / Vector Graphics:** رسوميات عالية الدقة تم إنشاؤها خصيصاً للمسرح والستائر والمعدات السينمائية.
